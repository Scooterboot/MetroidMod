## Building

Put a copy of the [Subworld Library dll](https://github.com/jjohnsnaill/SubworldLibrary/blob/master/SubworldLibrary.dll) in the `lib/` folder. After that, build the mod through the tModLoader ModSources screen as you would any other mod.
